# ServiceFone

A simple service business website focused on device or repair-related services.

## Overview
This repository contains a static front-end website for a service-based business. The landing page is designed for branding, service promotion, and quick business presentation.

## Features
- Service-focused homepage
- Responsive layout
- Modern styling
- JavaScript interactions

## Tech Stack
- HTML
- CSS
- JavaScript

## Getting Started
1. Clone the repository.
2. Open `index.html` in your browser.
3. Or use a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
